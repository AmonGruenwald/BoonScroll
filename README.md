# 🌿 BoonScroll

A calm, personal news website for your home network. Each person gets a daily feed of **curated content** — no infinite scroll, no algorithmic rabbit holes. Just a fixed number of interesting things, then you're done.

## Features

- **Multi-user** — each person has their own profile and feed
- **Interest-driven** — describe what you care about, Claude curates accordingly
- **Daily feed at 5 AM** — fresh content every morning, automatically
- **Mixed content types**: news articles, fun facts (AI-generated), YouTube videos, stock prices
- **Shareable links** — share any item with a URL, accessible by anyone on your network
- **Historical feeds** — navigate back to previous days
- **Anti-doomscroll** — fixed item count per day (default: 12), then you're done

## Quick start

### 1. Get an Anthropic API key

Sign up at [console.anthropic.com](https://console.anthropic.com) and create an API key.

### 2. Configure

```bash
cp .env.example .env
# Edit .env and paste your ANTHROPIC_API_KEY
```

### 3. Run with Docker

```bash
docker compose up -d
```

Open **http://localhost:8080** in your browser.

### 4. Add users & interests

1. Click **+ Add person** to create a user profile
2. Select your user and click **Interests** in the top bar
3. Describe what you care about (be specific!)
4. Click **Refresh feed** to generate your first feed

## Running without Docker

```bash
cd backend
pip install -r requirements.txt

# Set environment variables
export ANTHROPIC_API_KEY=your_key_here
export DB_PATH=./boonscroll.db
export FRONTEND_DIR=../frontend

uvicorn main:app --reload --host 0.0.0.0 --port 8080
```

### Manual feed generation

```bash
# Generate today's feed
python scripts/generate_feed.py

# Generate for a specific date
python scripts/generate_feed.py 2025-01-15
```

## Configuration

| Variable | Default | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | (required) | Your Anthropic API key |
| `ITEMS_PER_USER` | `12` | Number of feed items per user per day |
| `DB_PATH` | `/data/boonscroll.db` | Path to the SQLite database |

## Architecture

```
BoonScroll/
├── backend/
│   ├── main.py           # FastAPI app + scheduler
│   ├── models.py         # SQLAlchemy models
│   ├── database.py       # DB setup
│   ├── feed_generator.py # Scraping + Claude curation
│   └── requirements.txt
├── frontend/
│   ├── templates/
│   │   └── index.html    # Single-page app
│   └── static/
│       ├── css/app.css
│       └── js/app.js
├── scripts/
│   └── generate_feed.py  # Manual trigger
├── docker-compose.yml
├── Dockerfile
└── .env.example
```

- **Backend**: FastAPI + SQLite + APScheduler
- **Frontend**: Vanilla JS (no framework, fast and simple)
- **Curation**: Claude claude-opus-4-6 selects the most relevant items and generates facts
- **Schedule**: APScheduler runs `generate_all_feeds()` every day at 05:00 UTC

## Sharing items

Every feed item has a unique share URL: `http://your-machine:8080/shared/<token>`

Share it with anyone on your home network. They'll see the item without needing to log in.
